# シフト管理システム 部門別ルールまとめ

このシステムは **3部門** のシフトを1つのWebアプリ（Next.js + Supabase）で管理しています。
部門ごとに「シフトの考え方」「使う勤務記号」「自動生成のルール」が異なります。

| 部門 | URL | 生成方式 | スタッフ | データ保存 |
|------|-----|---------|---------|-----------|
| 検査室 | `/` | 制約付き自動割当（毎日ポジションを割り振る） | Supabase `staff`（8名・US担当フラグ） | `staff` / `requests` / `shifts` ほか |
| 栄養科 | `/eiyoka` | 曜日固定パターン＋手動上書き | コード直書き（7名） | `eiyoka_*`（上書き分のみ） |
| 看護師 | `/nurse` | 制約付き自動生成（夜勤→公休/日勤） | Supabase `nurse_staff`（35名） | `nurse_*` |

---

## 1. 検査室（`/`）

**考え方**：毎日、各スタッフを検査ポジション（A〜E）に割り当てる。US（超音波）担当できる人を「★」として管理し、★が必要な枠を確保する。

### スタッフ設定
- `staff` テーブル：氏名、`can_us`（US担当可＝★）、表示順
- 現在8名

### 休診日
- 毎週**日曜**
- **奇数週の土曜**（偶数週の土曜は診療あり）
- **祝日**
- 休診日は全員「全休」

### 配置ポジションと必要人数
| 記号 | 内容 | 人数 | 条件 |
|------|------|------|------|
| A | 血液検査 | 1名 | 誰でも可 |
| B | CBC | 1名 | 誰でも可 |
| C | 心電図 | 1名 | 誰でも可 |
| D | 昼１ | 1名 | 午後半休は不可 |
| E①〜④ | US専任・補助（★） | 計4名（休み人数分減） | E①は★必須・1日1名 |
| e①〜④ | US補助（★なし） | 上記の残り | ― |

### 自動生成ルール
- **Eグループに★（US担当）を最低1名**確保（E①に配置）
- **E①は1日1名**まで
- ★を**AとBの両方**には入れない（どちらか一方のみ）
- **月・水**（入院が多い日＝heavy）は★を**C・Dに入れない**
- **午前/午後半休**の人はEグループに入れない
- **午後半休**の人はD（昼１）に入れない
- **火・木・金・土**のC（心電図）は、★なしでまだC未経験の人を優先（C配置を均等化）
- E①の連続配置を避ける（前日E①の人にはペナルティ）
- ポジション回数が均等になるようスコアリングして選出
- **偶数週の土曜**は自動割当せず**手動入力**（土曜午後稼働は別途登録）

### 警告
- Eグループに★を割り当てられない日
- 割り当て可能なスタッフ不足
- ★なしで火木金土のC配置が0回の人

### 運用機能
- 下書きパターン保存・比較 → 確定 / シフトのリセット / 印刷・PDF / スマホ閲覧（スタッフ別・日付別）

## 2. 栄養科（`/eiyoka`）

**考え方**：各スタッフは**曜日ごとに基本シフトが固定**されている（例：谷口は木金土日が早出）。基本パターンを自動表示し、必要に応じて手動で上書きする。

### スタッフ（コードに直書き・7名）
| 氏名 | 役割・備考 |
|------|-----------|
| 谷口 | 献立作成 |
| 副島 | **管理栄養士**・発注 |
| 喜多 | 発注 |
| 松園 | ― |
| 藤井 | （短時間勤務 8-13 / 9-13） |
| 江原 | **自宅勤務あり**（火木金は自宅） |
| 西久保 | **管理栄養士**・献立作成 |

### 勤務記号
早出 / 日勤 / 遅出 / 遅出*（調理補助）/ 9事務 / 9遅出 / 8-13 / 9-13 / 自宅 / 休み / 希望休

### ルール
- **曜日固定の基本パターン**を各スタッフごとに保持（第n週で変わる人もいる：例 副島は第1日曜のみ「9事務」）
- **休診日**＝日曜・祝日（藤井・江原・西久保は土日祝休み）
- 休診日に「日勤」は発生しない（早出へ振替）
- **手動上書き**：セルをクリックして任意のシフトに変更（上書き分だけ `eiyoka_*` に保存）

### 定期タスク（自動表示）
- **土曜**：午前=保存食 / 午後=モップ（第1・3週）or 冷凍庫掃除（谷口担当・第2・4週）
- **日曜**：換気扇掃除＋毎月の掃除（第1・3週）/ モップ＋毎月の掃除（第2・4週）

### 警告
- **管理栄養士（副島・西久保）が不在**の日
- 出勤者が2名未満の日

### 運用機能
- ジョブカン用エクスポート（スタッフコード付き）/ 印刷

## 3. 看護師（`/nurse`）

**考え方**：内科病棟の月間シフト。まず**夜勤**を必要人数だけ埋め、夜勤明け「非」を置き、残りを**公休（✕）と日勤（日）**で埋める。Python+Excel版を移植したもの。

### スタッフ設定（`nurse_staff`・35名）
氏名 / 資格 / 夜勤可否 / 夜勤役割（両方可・夜正のみ・夜副のみ）/ 最大夜勤数（月）/ 連勤上限 ＋ **詳細条件**（下記）

### 勤務記号（Excel版と同一）
日 / 夜正 / 夜副 / 非（夜勤明け）/ ✕（公休）/ 年 / 振 / 付 / 看 / 特 ＋ 半日（/年・年/ など）

### 夜勤ルール（人数は設定画面で変更可）
- 曜日別の必要人数：初期値 **月・水・日＝2名、火・木・金・土＝3名**
- うち**夜正（リーダー）1名**、残りは夜副
- **夜勤上限**（月の最大夜勤数）・**連勤上限**を超えない
- 夜勤の翌日は自動で「非」（夜勤明け）
- **NG組み合わせ**（`nurse_ng_pairs`）：指定ペアは同じ夜勤に入れない

### 日勤・公休ルール
- **土曜の日勤＝5名 / 日曜・祝日の日勤＝3名**（設定画面で変更可）。週末勤務は公平にローテーション
- **平日**は人数を固定せず、各看護師の**公休（✕）が月の目標日数で揃う**よう、平日ごとの公休負荷を平準化（毎日の日勤人数が平均的になる）
- 公休目標日数：空欄なら土日祝の日数から自動
- 土日祝で必要人数を満たせない日は、可能な人数だけ配置して**警告**
- 連勤上限を超える場合は平日の日勤を公休に振替（土日祝の人数は維持）

### スタッフごとの詳細条件（スタッフ設定タブで編集）
| 条件 | 保存先 | 内容 |
|------|--------|------|
| 新人 | `nurse_staff.is_newbie` | 夜勤の必要人数にカウントしない（自動では夜勤に入れない） |
| 月公休 | `nurse_staff.kokyu_override` | 看護師ごとの月公休数を個別設定（空欄＝全体設定） |
| 特定曜日は夜勤不可 | `nurse_staff_rules`（no_night_dow） | 例：毎週水曜は夜勤に入れない |
| 毎週○曜は日勤固定 | `nurse_staff_rules`（fixed_day_dow） | 希望休が優先 |

### 運用機能
- 生成パラメータ（公休目標・乱数シード）を画面入力 / 下書きパターン保存・確定 / セル編集 / 印刷 / 個人別集計・日別「夜勤計・日勤計」表示

## 部門ごとの違い（要約）

| 観点 | 検査室 | 栄養科 | 看護師 |
|------|--------|--------|--------|
| 生成の起点 | ポジション割当 | 曜日固定パターン | 夜勤→公休/日勤 |
| 自動化度 | 高（毎日自動割当） | 低（固定＋手動上書き） | 高（制約付き生成） |
| 特別な役割 | US担当（★） | 管理栄養士 | 夜正（リーダー）・新人 |
| 休診/休み | 日曜・奇数週土曜・祝日 | 日曜・祝日 | なし（年中・夜勤あり） |
| スタッフ管理 | DB（画面） | コード直書き | DB（画面・詳細条件付き） |
| 主な制約 | ★確保・半休・C均等 | 管理栄養士在席 | 夜勤人数・連勤・NG・公休均等・曜日条件 |
